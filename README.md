# Ecommerce_sales_analysis

## Project Overview
This project analyzes e-commerce sales data using Microsoft Excel and presents the findings through an interactive sales dashboard.

The analysis focuses on sales performance across products, categories, regions, customer types, payment methods, and monthly sales trends.

The project demonstrates the complete process from structured sales data to business-focused analysis and dashboard visualization.
 
### Business Objective
The objective of this project is to analyze e-commerce sales performance and identify:

Top-performing products

Best-performing categories

Regional sales performance

Customer-type contribution to sales

Preferred payment methods

Monthly sales trends

Key sales KPIs

### Analysis

The dashboard provides insights into:

Product-wise sales

Category-wise sales

Regional sales performance

Customer type analysis

Payment method analysis

Monthly sales trends


### Key Insights

Electronics is the top-performing category, contributing approximately 74.7% of total sales.

Laptop is the highest-revenue product, generating approximately ₹41.18 lakh in sales.

Pune has the highest sales among the regions in the dataset.

Premium customers contribute the highest sales among the customer types.

COD is the highest-contributing payment method by sales.
